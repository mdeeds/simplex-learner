Neural Net & GPU Math Specifications

1. 3-Layer Network Formulation

Maps 2D spatial coordinates (x, y) ∈ ℝ² to scalar noise values ŷ ∈ [-1, 1]:

• Layer 1: Z&sub1; = W&sub1;·X + b&sub1; (16×2 weights + 16 biases = 48) → A&sub1; = tanh(Z&sub1;)
• Layer 2: Z&sub2; = W&sub2;·A&sub1; + b&sub2; (16×16 weights + 16 biases = 272) → A&sub2; = tanh(Z&sub2;)
• Layer 3: ŷ = W&sub3;·A&sub2; + b&sub3; (1×16 weights + 1 bias = 17)
• Total parameters: 48 + 272 + 17 = 337 parameters

2. WebGL GPU Math & Backpropagation

The network is evaluated across all canvas pixels via WebGL fragment shaders in parallel. The analytical gradients for MSE loss ℒ = ½∑(ŷ - y_target)² are computed via backpropagation:

• δ&sub3; = (ŷ - y_target)
• δ&sub2; = (δ&sub3; · W&sub3;) ⊙ (1 - A&sub2;²)
• δ&sub1; = (δ&sub2; · W&sub2;) ⊙ (1 - A&sub1;²)
• ∇W&sub3; = δ&sub3; · A&sub2;&E137;, ∇W&sub2; = δ&sub2; · A&sub1;&E137;, ∇W&sub1; = δ&sub1; · X&E137;
• Gradient update: θ← θ - η∇θ
